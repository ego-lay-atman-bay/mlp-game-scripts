# MLP game scripts

This is just a collection of random scripts that I created to do different tasks in the mlp game.

## Installation

You can install it by running

```shell
pip install mlp-scripts@git+https://github.com/ego-lay-atman-bay/mlp-game-scripts/
```

But it's probably a lot more useful if you clone the repo, so you can add your own scripts.

```shell
git clone https://github.com/ego-lay-atman-bay/mlp-game-scripts/
cd mlp-game-scripts
pip install -r requirements.txt
```

## Usage

If you installed it via pip, you can run it with

```shell
mlp-scripts -h
```

But if you cloned it, you can run it with

```shell
py -m mlp_scripts -h
```
